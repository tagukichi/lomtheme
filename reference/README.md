# reference/ — 既存サイトの取り込み置き場

このディレクトリに **Chrome 拡張「SingleFile」で保存した HTML** を置いてください。
置いたら以下を実行すると、`docs/site-analysis/` に解析レポートが生成されます。

```bash
python3 tools/extract_structure.py reference/
```

---

## 保存時の設定

| 項目 | 指定 |
|---|---|
| ログイン状態 | **ログアウトして保存**（管理バーや会員限定表示が混ざらないように） |
| 画面幅 | PC表示（1280px以上）。スマホ表示は別途スクショで可 |
| SingleFile 設定 | 既定のままで可 |

ページを開いてから **数秒待って**保存してください。遅延読み込み（Lazy Load）の画像や
スライダーが初期化される前に保存すると、その部分が欠けます。

## 追加で保存してほしいページ

`jaycee-sosiki` / `jaycee-keikaku` / `jaycee-sanjo` の3コンポーネントは、
CSSが読み込まれているのにマークアップが取得ページに出てきません。
**これらを使っているページが未取得**です。JCサイトで需要の高い機能なので、
実物を確認したいです。

| ファイル名 | 対象ページ |
|---|---|
| `07-sosiki.html` | 組織図 |
| `08-keikaku.html` | 事業計画 |
| `09-sanjo.html` | 賛助会員 |
| `10-search.html` | 検索結果 `/?s=事業` |
| `11-404.html` | 存在しないURL（例 `/zzz-test/`） |

**存在しないページは飛ばして構いません** — 何が無いかも解析の材料になります。
上記が玉野JCに無い場合、他のLOMで作られたページでも構いません。

## HTML以外に欲しい情報

テキストでもスクリーンショットでも構いません。`reference/notes/` に置いてください。

1. **プラグイン一覧** — 管理画面「プラグイン」の画面。**最重要**です。
   HTMLから推測できないもの（バックアップ、セキュリティ、SEO、会員管理など）が
   ここにしか出てきません。
2. **使用テーマ名**（親テーマ・子テーマ）
3. **固定ページ一覧** — 管理画面「固定ページ」の画面
4. **カスタム投稿タイプの有無** — 左メニューに「お知らせ」「事業」等の独自項目があるか
5. **Elementor Pro のライセンス有無**

## ファイルサイズについて

SingleFile は画像を base64 で HTML に埋め込むため、1ファイル 5〜15MB になります。
15ページで 100MB 超も有り得ます。解析自体は問題なく通りますが、
**このリポジトリは最終的に配布テーマの製品リポジトリになる**ため、
容量が気になる場合は解析後に `reference/` を別ブランチへ退避します。
（解析結果の Markdown は軽量なので `docs/` に残ります）
