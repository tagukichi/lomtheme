# 固定ページのレイアウト要件

tamanojc.com の「活動について」「入会のご案内」は中身が空のため、
別LOM（埼玉中央青年会議所）のページを参考として提示いただいた。
**添付のようなコンテンツ配置を、担当者が管理画面から組めるようにする**のが要件。

## 参考レイアウトの分解

### A. 活動について

```

ヒーロー画像（1枚・大きめ）
┌─ 本文カラム ────────────────┐  ┌─ サイドバー ─┐
```

繰り返し単位は **「見出し＋本文＋画像グリッド＋キャプション」** の1種類のみ。

## ACF フレキシブルコンテンツの設計

2ページ分の要素を洗い出すと、**7種類のレイアウト**で両方を組める。
他LOMへの展開でも使い回せる粒度にしてある。

| レイアウト名 | 用途 | 主なフィールド |
|---|---|---|
| `hero_image` | ページ冒頭の大きな画像 | 画像、表示比率（横長/縦長） |
| `lead` | 中央寄せのリード文 | テキスト（改行可） |
| `rich_text` | 本文ブロック | 本文、囲み枠の有無 |
| `section_gallery` | **見出し＋本文＋画像グリッド＋キャプション** | 見出し、本文、画像（繰り返し）、キャプション、列数(3/4) |
| `feature_cards` | 画像＋テキストのカード群 | カード繰り返し（小見出し、画像、本文、画像の左右） |
| `column_boxes` | 箇条書きボックスの横並び | ボックス繰り返し（見出し、項目リスト）、列数(2/3) |
| `info_box` | 申込み案内など | 見出し、番号付きリスト、補足テキスト |

`section_gallery` が「活動について」の中核、
`feature_cards` + `column_boxes` + `info_box` が「入会のご案内」の中核。

### 設計上の判断

**画像枚数を固定しない。** 参考ページでは3枚と4枚が混在している。
繰り返しフィールド＋列数指定にして、枚数に応じて自動でグリッドが組まれるようにする。
枚数ごとに別レイアウトを用意すると管理画面が煩雑になり、担当者が迷う。

**見出しレベルはテーマ側が決める。** 担当者にhタグを選ばせない。
ページタイトルが h1、`section_gallery` の見出しが h2、
`feature_cards` の小見出しが h3 と固定する。
これで `01-existing-site-findings.md` の h1欠落問題が構造的に再発しなくなる。

**サイドバーの有無はページ単位のON/OFF。** 参考ページはどちらもサイドバー有り。
トップページなど不要なページもあるため、ページごとに切り替えられるようにする。

## 想定するフィールドグループ

```
グループ: ページコンテンツ
  適用条件: 投稿タイプ = 固定ページ
  ├ hero_image        （フレキシブル）
  ├ lead
  ├ rich_text
  ├ section_gallery
  │   ├ 見出し           text
  │   ├ 本文             textarea
  │   ├ 画像             repeater → image
  │   ├ 列数             select  3 | 4
  │   └ キャプション      text
  ├ feature_cards
  │   └ カード           repeater
  │       ├ 小見出し      text
  │       ├ 画像         image
  │       ├ 本文         textarea
  │       └ 画像の位置    select  左 | 右
  ├ column_boxes
  │   ├ 列数             select  2 | 3
  │   └ ボックス          repeater
  │       ├ 見出し        text
  │       └ 項目          repeater → text
  └ info_box
      ├ 見出し           text
      ├ 番号付き項目      repeater → text
      └ 補足             wysiwyg

グループ: ページ設定
  ├ サイドバー表示        true_false（既定: 表示）
  └ パンくず表示          true_false（既定: 表示）
```

## 確認したい点

1. **ACF は Pro を前提にしてよいか。**
   フレキシブルコンテンツと繰り返しフィールドは **ACF Pro 専用機能**。
   Elementor Pro を切る判断をした以上、ここも揃えるなら
   ACF無しで同等の入力UIを自前実装する選択肢もある（工数は増える）。
2. 上記7レイアウトで足りない配置パターンが他LOMの事例にあるか。
