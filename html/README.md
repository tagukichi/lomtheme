# html/ — サイト本体

素の HTML / CSS / JavaScript で作った静的サイト。
ビルド工程もフレームワークも無く、`index.html` をブラウザで開けばそのまま動く。

公開URL: https://tagukichi.github.io/lomtheme/

---

## ファイル

```
index.html         トップ
greeting.html      理事長あいさつ
activity.html      活動について
news.html          最新情報 一覧（分類タブ付き）
news-detail.html   記事個別
join.html          入会のご案内
contact.html       お問い合わせ（フォーム）
privacy.html       個人情報保護方針
404.html           ページが見つかりません

assets/css/style.css   全ページ共通のスタイル
assets/js/main.js      全ページ共通のスクリプト
assets/img/            画像（すべて差し替え用のプレースホルダ）
```

## 各LOMへの展開

### 1. 文言を差し替える

`○○青年会議所` を各LOM名に一括置換する。あわせて次を差し替える。

| 対象 | 場所 |
|---|---|
| 郵便番号・住所・TEL・FAX・メール | 全ページのフッター、`join.html`、`contact.html` |
| SNSのURL | 全ページのフッター（`href="#"` になっている） |
| 理事長名・代数 | `index.html`、`greeting.html` |

### 2. 色を変える

`assets/css/style.css` の冒頭にある `:root` の変数だけ書き換えれば全体に反映される。
個別のセレクタを触る必要はない。

```css
--brand: #0097d7;   /* JCブルー */
--accent: #e8a33d;  /* 入会導線などの強調色 */
```

### 3. 画像を差し替える

`assets/img/` のプレースホルダを同じファイル名で置き換える。
推奨サイズは各SVGの中に書いてある（例: `1600 × 900`）。

| 用途 | ファイル | 推奨サイズ |
|---|---|---|
| メインビジュアル | `mv1〜3.svg` | 1600 × 900 |
| お知らせのサムネイル | `news1〜9.svg` | 600 × 800（縦3:4） |
| 活動写真 | `act1〜16.svg` | 800 × 600（横4:3） |
| ロゴ | `logo.svg` | 正方形 |

拡張子を変える場合（`.svg` → `.jpg` など）は、HTML側の `src` も直す。

## 作りの方針

**見出しは1ページにh1がちょうど1つ。** ページタイトルが h1、セクションが h2、
カードが h3。記事ページだけは記事タイトルが h1 になるので、上部の帯を置いていない。

**JavaScript が無くても内容は読める。** スライダーは1枚目が静止画として残り、
分類タブは全件が並ぶだけ。フォームも通常の送信で成立する。

**外部ライブラリを使っていない。** jQuery も Bootstrap もアイコンフォントも無い。
読み込むのは Google Fonts（M PLUS 1）だけで、それも外したければ
`<link>` を消せば OS 標準の和文フォントに落ちる。

**印刷に対応している。** ヘッダー・フッター・サイドバーを省いて本文だけ出る。

## 検査

ページを増やしたり編集したら実行する。

```bash
python3 tools/check_html.py html/
```

リンク切れ、h1の数、alt属性、タグの対応、`label for` の対応を見る。
GitHub Actions でも公開前に同じ検査が走り、問題があれば公開されない。
